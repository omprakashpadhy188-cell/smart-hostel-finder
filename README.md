# Smart Hostel Finder

A full-stack web application that helps students find suitable hostels based on budget, location, amenities and room requirements. Students can search and filter hostels, compare them side by side, and get a personalised ranked list. An admin page manages the data.

## Features
- **Search and filter** by city, gender, sharing (1 to 5), AC / Non-AC, food type and monthly rent.
- **Hostel details** with AC and Non-AC room prices, mess and laundry prices, and amenities.
- **Recommendations**: a Python scoring algorithm ranks hostels using a feature matrix and user-chosen weights.
- **Compare** 2 to 4 hostels side by side, with the best value in each row highlighted.
- **Admin CRUD**: create, edit and delete hostels (protected by an admin key), with data validation and JSON error responses.

## Setup

**Requirements:** Python 3.10+, MySQL Server 8.x, Git.

**1. Create the database.** Open the MySQL client (`mysql -u root -p`) and run:
```
source C:/path/to/smart_hostel_finder/data_base/schema.sql
source C:/path/to/smart_hostel_finder/data_base/seed_data.sql
```
Check: `SELECT COUNT(*) FROM hostels;` returns 88.

**2. Install the backend.**
```
python -m venv venv
venv\Scripts\activate          # macOS/Linux: source venv/bin/activate
pip install -r backend/requirements.txt
```

**3. Add your settings.** In `backend/`, copy `.env.example` to `.env` and fill in your MySQL password and an admin key. Never commit `.env`.

**4. Run the API.**
```
cd backend
python app.py
```
The API runs at `http://127.0.0.1:5000`.

**5. Open the frontend.** Open `frontend/index.html` in Chrome or Edge while the server is running. The other pages are linked from it; the admin page is `frontend/admin.html`.

## API reference
| Method | Route | Purpose |
|---|---|---|
| GET | `/api/health` | Server check |
| GET | `/api/hostels` | Search. Filters: `city`, `gender`, `food`, `max_budget`, `sharing`, `ac`, `limit` |
| GET | `/api/hostels/<id>` | One hostel with rooms and amenities |
| GET | `/api/compare?ids=1,2,3` | Compare 2 to 4 hostels |
| GET | `/api/amenities` | List of amenity names |
| POST | `/api/recommend` | Ranked recommendations (JSON body) |
| POST | `/api/admin/hostels` | Create a hostel (needs `X-Admin-Key` header) |
| PUT | `/api/admin/hostels/<id>` | Update a hostel (needs `X-Admin-Key`) |
| DELETE | `/api/admin/hostels/<id>` | Delete a hostel (needs `X-Admin-Key`) |

Errors return JSON such as `{"error": "..."}` with status 400, 401, 404 or 500.

## How the recommender works
1. **Hard filters** remove hostels that cannot work: wrong city or gender, a Veg or Non-Veg mismatch, or no available room that matches the sharing and AC choice within budget.
2. **Feature matrix**: each remaining hostel becomes a row of four scores between 0 and 1: price (cheapest total cost scores highest), distance, amenities matched, and rating.
3. **Weighted score**: `score = X @ w`, where `w` holds the user's weights (price, distance, amenities, rating), normalised to sum to 1.
4. Hostels are sorted by score and the top N are returned with a score breakdown.

## Dataset
The data is **synthetic** (generated by `data/generate_dataset.py`): 88 hostels in 11 Indian cities with 1 to 5 sharing rooms, AC / Non-AC prices, mess and laundry prices. Names, phone numbers and prices are made up and are not real listings.
